CodeCoach updates this table after every practice problem. **Level** = highest ladder rung solved without hints:
R0 write one line (toolkit drill) - R1 trace (predict output) - R2 unscramble lines - R3 fill in blanks - R4 debug/modify - R5 write from exact spec - R6 write from a word problem.
**Mastered** = 3 different, never-seen R5/R6 problems solved with no hints, the last one timed within the target time. Mastered topics get spaced reviews with growing gaps (2, 5, 12, 30, 75 days...); a review that needed help repeats the same gap, and a failed review drops the topic back to not mastered.
